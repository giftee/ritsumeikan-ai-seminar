# 事前セットアップ手順書

勉強会に参加する前に、このページの準備をお願いします。

準備は「必須」と「推奨」に分かれています。**必須の2つ（約5分）ができていれば当日参加できます。** 推奨の準備（約15分）までできると、手元でアプリを動かしながら参加できます。

## 必須1: 生成AIツールが使えること

当日、AIに修正方針を相談するハンズオンがあります。次のどちらかの形で、AIにメッセージを送れる状態にしてください。

当日利用できるAIツールは **GitHub Copilot / Claude / ChatGPT / Cursor / Gemini** の5つです。どのツールを選ぶ場合も、ブラウザのチャット画面ではなく、**エディタの中またはCLI（ターミナル）で使える状態にしておくのが理想**です。リポジトリのコードをAIが直接読めるため、コードの貼り付けが不要になり、実務のAI活用に近い形で参加できます。

チャット型AIはリポジトリの中身を読めないため、当日はコード（100行程度）を自分で貼り付けて相談します。今回の教材は公開されている学習用リポジトリなので、貼り付けて問題ありません。ただし実務や研究では、未公開のコードやデータをAIに貼ってよいかは所属のルールを必ず確認してください。これも当日扱うテーマの1つです。

当日は次のリポジトリのIssueとPull Requestを読みます。開けることを確認してください。

- https://github.com/giftee/ritsumeikan-ai-seminar

当日行うのはこのリポジトリの閲覧とcloneだけで、pushやPR作成は行いません。

## 推奨: ローカル環境で教材アプリを動かす

ここから先は必須ではありませんが、できていると当日の理解が深まります。うまくいかなくても、当日は講師の画面共有で進められるので安心してください。

### 1. Node.js のインストール

**バージョンに注意**: Node.js 22.12.0以上

https://nodejs.org/ から LTS版（v22系）のインストーラーをダウンロードして実行してください。

確認方法（ターミナル / PowerShell）:

```bash
node -v
# v22.12.0 以上と表示されればOK
npm -v
# バージョン番号が表示されればOK
```

すでにNode.jsが入っている人も `node -v` を必ず確認してください。v21系やv20.18以下の場合は、LTS版を入れ直してください。

### 2. Git のインストール

- **Windows**: https://git-scm.com/downloads から「Git for Windows」をインストール（設定はすべてデフォルトでOK）
- **Mac**: ターミナルで `git --version` を実行。未インストールの場合はコマンドラインツールのインストールを促すダイアログが出るので、指示に従ってください

確認方法:

```bash
git --version
# バージョン番号が表示されればOK
```

### 3. リポジトリのcloneとセットアップ

ターミナル（Windowsの人はPowerShell）で、作業したいフォルダに移動してから実行します。

```bash
git clone https://github.com/giftee/ritsumeikan-ai-seminar.git
cd ritsumeikan-ai-seminar
npm install
npm test
```

`npm test` で `1 passed` と表示されればOKです。

### 4. アプリの起動確認

```bash
npm run dev
```

ブラウザで http://127.0.0.1:5173/ を開いてください。

**確認ポイント**: 「差し入れeギフト推薦」の画面が表示され、場面「研究室」の初期状態で `コンビニスイーツ` が推薦され、右上に `要レビュー` と表示されていれば成功です。**この「要レビュー」が当日の題材です。なぜこの結果がおかしいのか、考えておいてください。**

確認できたら、ターミナルで `Ctrl+C` を押してサーバーを終了します。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `node` / `git` が「コマンドが見つかりません」になる | インストール後にターミナルを開き直してください |
| `npm run dev` がバージョンエラーで止まる | `node -v` を確認。v21系・v20.18以下はLTS版（v22系）を入れ直してください |
| `npm install` がエラーになる | エラーメッセージの最初の数行をメモしておいてください。当日質問できます |
| http://127.0.0.1:5173/ が開けない | `npm run dev` のターミナルに表示されたURLを使ってください（ポートが変わることがあります） |

**解決できなくても大丈夫です。** 必須1・2ができていれば当日のハンズオンには参加できます。エラー内容をスクリーンショットで残しておくと、当日の質疑で相談できます。
