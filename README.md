# ritsumeikan-ai-seminar

立命館大学向け AI x GitHub 勉強会のハンズオン教材です。

このリポジトリでは、研究室・サークルの差し入れeギフト推薦ロジックを題材に、AIの出力をGitHub上でチームが判断できる形にする練習をします。

## 学生向け資料

- [事前セットアップ手順書](./docs/setup_guide.md) ※参加前にこちらを確認してください
- [当日ハンドアウト](./docs/student_handout.md)

## 教材画面のデザイン原則

この教材の画面は、ギフティのデザイン原則に合わせて作っています。

- あたたかみ: 差し入れを受け取る相手や場面の温度感が伝わる表現にする
- ひかえめ: ギフトを贈る人と受け取る人を主役にし、UIは判断を支える程度に抑える
- かんたん: 条件、候補、レビューすべき点がすぐ分かるようにする

## 今日やること

1. Issueを読む
2. AIへの依頼文を書く
3. AIの修正方針をPlan Gateで判断する
4. 講師準備済みPRを読む
5. Conversation / Files changed / Checks を確認する
6. Reviewコメントを書く
7. 次回AIに渡す学びを残す

## 当日必須ではないこと

- ローカル環境の構築
- Branch作成
- Commit作成
- Pull Request作成

このリポジトリへのpushやPR作成は行いません（閲覧のみ）。余裕がある人は、発展課題としてローカルでの実装まで進めてください。

## 任意: ローカル環境セットアップ

ローカルで実装やテストまで試したい人向けの手順です。当日のハンズオンでは必須ではありません。

### 前提

- Node.js 20.19.0以上の20系、または22.12.0以上（22.12.0以上を推奨）
- npm
- Git

Viteの対応範囲に合わせているため、Node.js 20.0.0から20.18.x、および21系では起動できません。パッチバージョンまで完全に固定する必要はありません。

### 手順

```bash
git clone https://github.com/giftee/ritsumeikan-ai-seminar.git
cd ritsumeikan-ai-seminar
npm install
npm test
npm run dev
```

テストが通り、開発サーバーが起動したら、ブラウザで `http://127.0.0.1:5173/` を開いてください。研究室・サークル・勉強会の条件を切り替えながら推薦結果を確認できます。終了するときは、ターミナルで `Ctrl+C` を押します。

`main` ブランチでは、あえて推薦ロジックに見落としが残っています。PRレビューでは、画面上の結果とテストの両方を手がかりにして、AIの修正をそのまま受け入れてよいかを判断します。

### 発展課題（ローカルのみ・pushしない）

Issue #1 の完了条件を満たすように、`src/giftRecommendation.js` を自分で（またはAIと）修正し、テストを `test/giftRecommendation.test.js` に追加して `npm test` を通してください。

できたら、講師準備済みのPR #2 の Files changed と自分の差分を見比べてください。実装の違い、テストの違い、どちらが読みやすいかを考えることが、そのままレビューの練習になります。

ローカルでブランチを切って作業しても構いませんが、このリポジトリへのpushはできません。
