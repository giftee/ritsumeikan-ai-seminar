# Issue 01: 研究室・サークルの差し入れeギフトを条件に合わせておすすめする

研究室の発表会後やサークルの作業会後に、メンバーへ配る差し入れeギフトを1つおすすめする関数があります。
現在の実装では、予算内かつ在庫ありの最初のギフトを返しているため、好みに合わないギフトや、除外したいカテゴリのギフトが選ばれることがあります。

## 期待する仕様

- `profile.budget` は1人あたりの予算を表す数値
- `profile.preferredTags` は好みを表すタグ配列
- `profile.excludedCategories` は選びたくないカテゴリ配列
- `gift` は `name`、`price`、`category`、`tags`、`available` を持つ
- `available` が `true` のギフトだけを候補にする
- `price` が `profile.budget` 以下のギフトだけを候補にする
- `category` が `profile.excludedCategories` に含まれるギフトは候補にしない
- `preferredTags` と1つ以上一致するギフトだけを候補にする
- 一致したタグ数が多い順におすすめする
- 一致数が同じなら安い順におすすめする
- 候補がなければ `おすすめできるギフトがありません` を返す
- 外部API連携、個人情報の保存、AIによる自由文メッセージ生成は今回の範囲外

## 完了条件

- 仕様を満たす実装になっている
- 予算、在庫、除外カテゴリ、好みタグ一致数、同点時の安い順を確認するテストが追加されている
