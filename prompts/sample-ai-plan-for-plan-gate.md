# Plan Gate判定用サンプル計画

あるAIが出した修正計画です。実装に進めてよいか、`plan-gate-checklist.md` の観点で判断してください。

---

## 仕様の理解

予算内、在庫あり、避けたいカテゴリ以外で、好みタグに合うギフトを1つ推薦する関数に修正します。

## 修正方針

1. `available` と `price <= budget` のフィルタは維持する
2. `excludedCategories` に含まれる `category` のギフトを候補から除外する
3. `preferredTags` との一致数を数え、一致数が多い順に並べる
4. 一致数が同じ場合は、ギフト名の五十音順で先のものを選ぶ
5. より良い推薦のため、SNSトレンドAPIから人気スコアを取得し、同点時の補助スコアとして使う
6. 候補がなければ `おすすめできるギフトがありません` を返す

## 追加するテスト

- 予算超過のギフトが選ばれないこと
- 在庫なしのギフトが選ばれないこと
- 一致数が多いギフトが優先されること

## 変更ファイル

- `src/giftRecommendation.js`
- `src/app.js`
- `test/giftRecommendation.test.js`

## 講師向けメモ（判断が終わるまで学生には見せない）

このサンプルに仕込んである問題:

1. 同点時の決め方を「五十音順」と勝手に決めていて、質問として出していない
2. SNSトレンドAPIは、頼んでいない外部API連携の追加（スコープ逸脱）
3. 直したい問題そのもの（避けたいカテゴリの除外）と同点時のテストが、追加テスト一覧にない
4. 変更範囲を `src/app.js` まで広げている（依頼は2ファイル限定）

進行のポイント:

- 「一見それらしい計画ほど、決まっていない点を黙って埋めている」ことに気づかせる
- 五十音順という仮決め自体が悪いのではなく、質問せずに決めたことが問題だと強調する
- 判断はRequest changes相当。「AIの計画は候補であって完成品ではない」につなげる
