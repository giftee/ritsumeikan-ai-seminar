# Plan Gate判定用サンプル計画

あるAIが出した修正計画です。実装に進めてよいか、`plan-gate-checklist.md` の観点で判断してください。

---

## 仕様の理解

予算内、在庫あり、避けたいカテゴリ以外で、好みタグに合うギフトを1つ推薦する関数に修正します。

## 修正方針

1. `available` と `price <= budget` のフィルタは維持する
2. `excludedCategories` に含まれる `category` のギフトを候補から除外する
3. `preferredTags` との一致数を数え、一致数が多い順に並べる
4. 一致数が同じ場合は、ギフト名の五十音順で先のものを選ぶ
5. より良い推薦のため、SNSトレンドAPIから人気スコアを取得し、同点時の補助スコアとして使う
6. 候補がなければ `おすすめできるギフトがありません` を返す

## 追加するテスト

- 予算超過のギフトが選ばれないこと
- 在庫なしのギフトが選ばれないこと
- 一致数が多いギフトが優先されること
