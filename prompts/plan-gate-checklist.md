| 観点 | 確認すること |
|---|---|
| 目的 | Issueの目的とずれていないか |
| 範囲 | 変更対象を広げすぎていないか |
| 制約 | 予算、在庫、除外カテゴリ、好みタグ一致、同点時の安い順、範囲外を扱っているか |
| テスト | バグ再現、予算、在庫、除外カテゴリ、好みタグ一致数、同点時の安い順が含まれているか |
| 不明点 | 勝手に決めず、質問すべき点を質問しているか |
| GitHub | Issueとの紐づけ、PR説明、CI、Review観点があるか |
