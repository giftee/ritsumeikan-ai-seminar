# Plan Gateチェックリスト

AIが修正方針を出したら、実装に進む前に次を確認する。

| 観点 | 確認すること |
|---|---|
| 目的 | 依頼の目的とずれていないか |
| 範囲 | 変更対象を広げすぎていないか |
| 決まっていない点 | 勝手に決めず、質問として出しているか |
| テスト | 直したい問題を再現・防止するテストが含まれているか |
| 範囲外 | 頼んでいない機能を勝手に追加していないか |
| GitHub | Issueとの紐づけ、PR説明、CI、Review観点があるか |

## 判断

```markdown
判断: Approve / Request changes
理由:
このAIが「勝手に決めていたこと」:
追加で確認したいこと:
```
